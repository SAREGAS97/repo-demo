# repo-demo
Учебный репозиторий для практики работы с Git: локальные репозитории, клонирование, ветки. Проект связан с курсом «Основы синтаксиса языка программирования Python».

Основные темы курса:

Переменные и типы данных
Условные операторы (if/elif/else)
Циклы (for, while)
Функции и область видимости
Работа со списками, словарями и кортежами

Пример задачи из курса: написать функцию, которая принимает список чисел и возвращает сумму чётных элементов. Решение демонстрирует работу с циклами, условиями и функциями.

## Шаг 2. Если есть виртуальное окружение — активируй его:

   source venv/Scripts/activate
python main.py
