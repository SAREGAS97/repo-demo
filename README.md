# repo-demo
Учебный репозиторий для практики работы с Git: локальные репозитории, клонирование, ветки. Проект связан с курсом «Основы синтаксиса языка программирования Python».

Основные темы курса:

Переменные и типы данных
Условные операторы (if/elif/else)
Циклы (for, while)
Функции и область видимости
Работа со списками, словарями и кортежами

Пример задачи из курса: написать функцию, которая принимает список чисел и возвращает сумму чётных элементов. Решение демонстрирует работу с циклами, условиями и функциями.

## Как запустить проект

1. Убедись, что у тебя установлен Python (проверь командой `python --version` или `python3 --version`).
2. Перейди в папку проекта:
   ```bash
   cd repo-demo
Запусти основной скрипт:   
python main.py (для Windows)
Или:
python3 main.py  (для macOS/Linux)


Это пример: подставь имя своего файла вместо `main.py`, если оно другое. Markdown автоматически сделает заголовки, списки и блоки кода.

## Шаг 3. Сохрани изменения

- В **nano**: `Ctrl+O` → `Enter` → `Ctrl+X`.
- В **VS Code**: нажми `Ctrl+S` (или меню «Файл → Сохранить»).
- В **блокноте**: «Файл → Сохранить».

## Шаг 4. Скажи Git, что файл изменился

После сохранения сделай:

```bash
git status

Ты увидишь, что README.md теперь в списке modified (изменённый), а не untracked.

Теперь добавь изменения в индекс:
git add README.md
